# hxyfront-62002 巡演灯位映射台

源提示词编号：2

巡演 Cue 要带去不同剧场，而各场灯光编号与备用灯情况不同。本工具把占位页升级为「巡演灯位映射台」：

- **预置三座剧场与灯具清单**（北京京演大剧院 / 上海浦京剧场 / 广州珠江舞台），可逐场登记灯位、通道、色片、焦点与备用灯，支持自定义新增/删除灯具与灯位筛选。
- **Cue 版本化导入**：JSON 导入只追加新版本，旧版本与导入时的原始 Cue 顺序永不覆盖；可在版本间切换查看。
- **逐场自动配灯**：导入后按「位置 → 色片 → 焦点」匹配，常规灯优先、备用灯兜底；同一 Cue 内同通道被两盏需求争用、色片不符、或无备用灯时，该 Cue 留待映射并给出具体原因。
- **人工点用**：待映射需求可手工选灯（自动拦截 Cue 内通道争用），人工结果在任何重算中保留。
- **临时换灯**：选定停用灯与顶替备用灯（备用灯占原通道、色片以备用灯实际为准）后，**只重算引用该灯的 Cue**，其他 Cue 与其他剧场结果原样保留；可一键换回。
- **持久化**：所有「剧场 × 版本」的逐场配灯结果保存在 localStorage，页面重开后原样可见；支持恢复预置。
