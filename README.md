# 巡演灯位映射台 · Touring Rig Map

同一套巡演 Cue 带到不同剧场，灯具编号、通道、备用灯都不一样。本工具把每座剧场的灯具登记清楚，导入 Cue 后按「灯位 → 色片 → 焦点」自动配灯，并校验通道争用与备用灯。

## 功能

- **预置三座剧场**：北京·星光大剧院 / 上海·江安大剧场 / 广州·海珠实验剧场，各自灯具编号、通道号、色片、可达焦点、备用灯情况不同（含共回路、缺备灯、色片差异等真实场景）。
- **逐场登记**：舞台平面灯位图 + 灯具清单（通道、色片、焦点一目了然），可按面光/耳光/顶光/侧光/逆光/追光筛选。
- **导入 Cue 自动配灯**：按 位置 → 色片 → 焦点 匹配主灯；同一 Cue 内通道争用、色片不符、焦点不可达、无备用灯时，该 Cue **留待映射**并逐条列出原因。
- **版本不可变**：每次导入生成新版本，Cue 原始顺序按数组保留，旧版本及其在各剧场的配灯结果永不覆盖，可随时切回查看。
- **临时换灯增量重算**：某盏灯停用并指定顶替灯后，只重算引用这盏灯（主灯或备灯）的 Cue；其他 Cue 与另外两座剧场的结果原样保留，可一键撤回。
- **配灯履历**：每个 Cue 保留导入配灯 / 换灯重算 / 撤换重算的逐条历史。
- **本地持久化**：版本、逐场配灯结果、换灯状态全部存入 localStorage，页面重开仍在。

## Cue 表导入格式（JSON）

```json
{
  "label": "v1 巡演首版",
  "sheet": "tour-cues-v1",
  "cues": [
    {
      "no": "Cue 12",
      "name": "冷蓝开场",
      "note": "开幕前 30 秒起",
      "reqs": [
        { "position": "面光1", "gel": "L201冷蓝", "focus": "全台", "level": 55 }
      ]
    }
  ]
}
```

- 灯位：面光1 / 面光2 / 左耳光 / 右耳光 / 一顶 / 二顶 / 左吊笼 / 右吊笼 / 逆光 / 追光位
- 色片：L201冷蓝 / L117暖粉 / L019天蓝 / R022深红 / R341暖橙 / R119墨绿 / P070月白 / 无
- 焦点：表演区A / 表演区B / 表演区C / 门口 / 后区 / 前台 / 全台

## 技术栈

React + Vite + TypeScript，无后端，数据保存在浏览器 localStorage。
